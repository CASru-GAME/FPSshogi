# 攻撃・スキルのモーション確認

全8駒の通常攻撃・副操作・スキルをUnityの実対戦シーンで確認した。既存の武器モデルを使い、握る位置と刃・銃口の向きに合わせて動作を作り直した。

| 駒 | 確認した問題と変更 |
| --- | --- |
| 歩 | 槍が立ち上がる動きから、引いて刃先の方向へ突き出す動きへ変更。跳び込みには槍を前へ構える動作を追加。 |
| 香車 | 短銃に発射直後の反動と復帰を追加。ズーム時に構えを寄せ、閃光弾の投擲時は銃を下げる。 |
| 桂馬 | モデル中心で回っていた刀を、柄を軸に右から左へ振り抜く動きへ変更。突進の到達時に斬撃を合わせる。 |
| 銀 | 薙刀の柄を軸にした斬撃へ変更。3秒の防御強化中は防御姿勢を保持し、通常攻撃後も効果が残れば戻す。 |
| 金 | 薙刀の斬撃と、5秒の防御強化に対応する構えを修正。 |
| 角 | 長銃に反動とズーム姿勢を追加。上昇中は構えを収め、滞空中は射撃姿勢へ戻す。 |
| 飛車 | 弦の解放、矢の消失、番え直しを連動。表示される矢の位置から射出し、減速フィールド発動に弓を差し出す動作を追加。 |
| 王 | 短刀を前方への突きへ変更。軍配を出す間は短刀を下げる。砲台の銃身を相手の高さへ向け、射撃反動を追加。 |

近接攻撃の有効時間と表示を同じ時計で進め、当たり判定を動いた武器の範囲へ更新する。ダメージ、再使用間隔、強化時間、王を倒す勝利条件、自動成りは従来どおり。

全検証で実行時エラー0。独立レビューで見つかった防御→突進の姿勢の跳ねと、低い壁への矢の初期めり込みも再現して修正した。弓は障害物との接触を発射時に解決し、密着した相手へのダメージを維持する。連戦時の破棄済み武器参照も修正した。

録画した連続フレームから全8種の見え方を確認。長柄武器は防御中に画面を横切り、通常の斬撃と桂馬の突進では握りを上げて刃が視界を通るようにした。修正前の17件の失敗、および追加した姿勢・接触・斬撃の失敗記録は各`Motion-*-Red`と`Motion-Cover-Focused`に保存している。

入力検証・録画は仮想ゲームパッドを使用。録画は1/30ゲーム秒ごとの実画面で、物理コントローラー2台の実機操作は未確認。
