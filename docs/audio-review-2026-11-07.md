# FPS将棋の効果音

以前は決定・取消・エラー・被弾・防御に短いサイン波を使い、武器、スキル、駒を指す動作や足運びに音がありませんでした。木、布、革、金属、弓、黒色火薬銃などのCC0素材を編集し、58種類の操作に97個の音声を割り当てています。

[効果音を試聴](../AudioReview/index.html)（リポジトリをダウンロードしてブラウザーで開く） · [素材の作者・ライセンス](../THIRD_PARTY_AUDIO.md)

| 駒 | 攻撃 | スキル |
| --- | --- | --- |
| 歩 | 槍の短い風切り音と衣擦れ | 踏み切りと前方への跳躍 |
| 香 | 短銃の破裂音 | 閃光弾を取り出して投げる音、実際に爆発した位置での破裂音 |
| 桂 | 刀を振る風切り音と刃の音 | 踏み込み、到達時の斬撃を別々に再生 |
| 銀 | 薙刀の長い振り | 高めの金属音で防御強化、効果が切れたときの音 |
| 金 | 薙刀の長い振り | 低い金属音で防御強化、効果が切れたときの音 |
| 角 | 短銃より低く余韻のある長銃 | 上昇に合わせた風切り音 |
| 飛 | 弦を放つ音、矢を再びつがえる音、物に刺さる音 | 減速領域の展開、効果を受ける側の出入り |
| 王 | 短刀の速い振り | 軍配、砲台の設置・発砲・撤収 |

盤面ではカーソル・駒の選択・通常の一手・持ち駒を打つ音を区別します。成りの音は新たに成ったときだけです。メニュー、参加・準備完了・離脱・切断・復帰、秒読み・開始・引き分け・勝敗にも音があります。マウスで駒を指したときに、独立したカーソル移動の音は重ねません。

足音は移動入力ではなく、接地して実際に進んだ距離で鳴ります。和室の畳と木の盤・家具で音を変え、着地とよじ登りも区別します。防御姿勢・解除、照準の切り替え、被弾・防御成功・倒されたとき、スキル再使用可能時にも対応します。クールダウン中の空押しで攻撃音は鳴りません。

設定は「全体音量」「効果音」「操作音」です。音量を変えるとその種類の音で試せます。1Pと2Pは共通の音声出力を使い、所有者を左右に少し振り分けます。着弾や砲台は両者からの距離で音量と左右を決めます。繰り返す音は直前と違う素材を選びます。一時停止中は戦闘音を止め、操作音は継続します。最後の攻撃と倒れる短い音は決着表示に残し、王を取った場合は対局終了の合図を一度だけ鳴らします。

音の検証では実際のTitle/Mainシーンを使い、Input Systemのマウス・コントローラー入力、受理された武器・スキル、HP・状態の変化、和室の床・盤への接地を追跡します。Windows検証版では共有AudioListenerの出力をPCMで録音し、無音、クリッピング、同時発音を検査します。物理コントローラー2台による試聴はこの自動検証の対象外です。

音声の検証はUnityエディター153件、Windows検証版176件を通過しました。どちらも58種類すべての再生を記録しました。Windowsの録音11本の最大ピークは −9.70 dBFS、両プレイヤーが同時に攻撃する場面では −12.99 dBFS でした。全体音量を0にした別の録音は全サンプルが0です。[録音ファイルの測定値](../AudioReview/Native/pcm.tsv)

## 素材の再生成

Unityプロジェクトの利用にPythonや追加ダウンロードは不要です。効果音自体を編集し直す場合だけ、Python 3.13で `python -m pip install -r Tools/audio-requirements.txt`、`python Tools/prepare_audio.py`、`python Tools/check_audio_assets.py` の順に実行してください。入力は `AudioSources/raw/`、出力は `Assets/App/Resources/Audio/` です。[manifest.json](../AudioSources/manifest.json)に全音声の素材・編集内容・SHA-256を記録しています。
