# FPS将棋 UIの下地整理

ユーザーの修正依頼: 白いウィンドウの上にUIを重ねた構成が冗長なので、他のゲームを参考にすっきりさせる。既に採用された左メニュー、既存の和室・盤・駒、平易な日本語、アイコンとゲージを維持してゲーム本体を修正する。

## 方針

白い外枠を外し、文字・細い区切り・選択位置で情報を整理する。単純な黒パネルへの色替えは行わない。読みやすさは背景に溶ける暗いグラデーションで確保し、3Dモデルを見せる。タイトルと一時停止は左側の文字メニュー。参加画面は左右の機器アイコンと状態。設定はラベルと値を揃えた行。説明画面は見出しと細い区切り。盤面とFPSは画面端に情報を置く。

メニュー表示中は盤面・FPSのHUDを隠し、再開時に元のHUDを復帰する。駒の選択とゲーム状態は保持する。終了確認・切断・読み込み失敗も同じ表現を使う。通常ボタンは透明で、選択中の下線と淡い強調だけを表示。操作領域は元と同じか広くする。

## 比較した方向

- 白パネルの面積だけ削減: 変更は少ないが、ウィンドウが積み重なる根本が残る。
- 文字中心のメニューと背景グラデーション: 和室と駒を生かす既存方針に合うため採用（実装者の判断）。
- 全操作を3D空間に配置: 読みやすさと2人の機器操作が複雑になるため今回は採用しない。

外部素材は参照のみでゲームに取り込まない。ゲームルール、入力の割当と準備確認、クールダウンの意味は維持する。

## 完了条件

主要画面から白い外枠と重複HUDが消え、720p以上で読める。フォーカスがキーボード・コントローラー・マウスで分かる。戻る・再開・切断復帰を既存の実シーン検証で確認する。Windowsビルドを更新し実画面を確認する。
