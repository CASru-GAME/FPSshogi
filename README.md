# FPS将棋

将棋の盤面と、駒同士のFPS戦闘を交互に進めるローカル2人対戦ゲームです。王をFPSで倒すと勝利します。王手・詰み判定はなく、成りは自動です。

## Unityで開く

1. このリポジトリをcloneする。
2. Unity Hubにプロジェクトフォルダーを追加し、**Unity 6000.2.12f1**で開く。
3. `Assets/App/Scenes/Title.unity`を開いてPlayする。

モデル・画像・復元した素材はリポジトリに含まれます。Google Driveからの追加取得は不要です。パッケージはUnityが初回起動時に取得します。

Windowsでは`Open-FPSshogi.cmd`でも開けます。Unityを独自の場所へインストールした場合は、環境変数`UNITY_EDITOR_PATH`に`Unity.exe`のフルパスを指定してください。

新しいUIは実行時に生成されます。停止中のシーンに残る旧Canvasは実行時に無効になります。

## 対局を始める

コントローラー2台、またはキーボード＋マウスとコントローラー1台を使用します。

タイトルの「対局」を選び、各自の機器でA / Enterを押すと参加します。参加した順に1P・2Pが決まります。割当を確認して、もう一度A / Enterを押すと準備完了です。両者の準備が完了すると対局が始まります。

| 操作 | キーボード＋マウス | コントローラー（Xbox表記） |
| --- | --- | --- |
| 盤面の選択 | WASD / マウス | 十字キー / 左スティック |
| 盤面の決定・取消・持ち駒 | F / C / E | A / B / X |
| FPSの移動・視点 | WASD / マウス | 左 / 右スティック |
| 攻撃 / 防御・ズーム | 左 / 右クリック | RT / LT |
| スキル / 登る | E / Space | B / A |
| メニュー | Esc | START |

駒ごとの武器・スキル・動きは「遊び方 → 駒の説明」で確認できます。

近接攻撃が届く位置に相手がいると、自分の照準の左右に括弧が付きます。

相手の駒を取りに行くと、攻める側は移動元、守る側は移動先のマスに立ち、向かい合って決闘が始まります。ほかの駒は盤上に残ります。開始距離は縦横の隣が約5.22m、桂馬の跳びが約11.68m、盤の隅から対角の隅が約59.09mです。

タイトルまたは対局中の「設定」で、1P・2Pそれぞれの視点感度と「ズーム感度（パッド）」を調整できます。初期値は通常2.0、ズーム0.8です。すでに視点感度を変えている場合は、その40％を最初のズーム感度に使います。

同じ画面の「垂直視野角（FOV）」で、決闘中の視野角を1P・2P別々に50〜140°の範囲で調整できます。初期値は60°です。

「設定」で全体音量・効果音・操作音を別々に調整できます。効果音と元録音はプロジェクトに含まれます。[効果音の試聴ページ](AudioReview/index.html)はローカルで開いて使えます。作者と利用条件は[音声素材のクレジット](THIRD_PARTY_AUDIO.md)を参照してください。

## 調整用のプレイ記録

2人が参加して対局を始めると、この端末に1局ずつ自動保存します。「設定」→「プレイ記録をCSV出力」→「出力先を開く」で、Excelなどで読める2つのCSVを取り出せます。毎回、それまでの全対局を新しいフォルダーに書き出します。両方の表は「対局ID」で対応します。

| ファイル | 1行の単位 | 記録内容 |
| --- | --- | --- |
| matches.csv | 1対局 | 開始・終了日時（UTC）、勝者、プレイ時間、手数、駒打ち回数、決闘数、両席の入力方式、ゲーム版・ビルドID |
| duels.csv | 1決闘の1人分（各決闘2行） | 仕掛けた側、攻め駒の移動元と守り駒のマス（筋・段）、開始距離、双方の駒と成り、勝敗、決闘時間、HP、通常攻撃の回数・命中率・距離、スキル・砲台別の与ダメージ、被ダメージ、完全防御数 |

通常攻撃は実際に振った回数・撃った回数を数えます。防御された攻撃も命中に含み、ダメージには実際に減ったHPを使います。平均攻撃時距離は攻撃した瞬間の両者の距離、平均命中距離は命中した攻撃の起点から相手までの距離です。分母が0の命中率や平均距離は空欄です。ポーズ・カウントダウン中の時間はプレイ秒数から除きます。

勝率を調べる際は「この席の結果」で勝ち・負け・相打ちを選べます。「中断」は終了やタイトルに戻る操作で打ち切った記録、「未完了」は対局中の書き出しや強制終了時の途中記録です。中断した対局でも、すでに決着した決闘は集計できます。

Windows版の元記録は `%USERPROFILE%\AppData\LocalLow\CASru\FPSshogi\PlayData\Matches`、書き出し先は同じ `PlayData` 内の `Exports` です。元記録は手や決闘の区切りと約5秒ごとに更新します。機器はパッドまたはキーマウの区分だけを保存し、ネットワーク送信は行いません。Unityエディターの記録は `PlayData-Editor` に分けています。

## Windows版をビルドする

Unityのメニューから`FPSshogi → Build Windows`を実行します。出力先は`Builds/FPSshogi/`です。実行・配布にはフォルダー全体が必要です。`FPSshogi.exe`を起動してください。

ビルド・Library・一時的な作業ファイルはGit管理に含めません。

## 実装と検証

UI、機器選択、将棋ルール、FPS戦闘の修正を含みます。変更内容と検証範囲は[UI-IMPLEMENTATION.txt](UI-IMPLEMENTATION.txt)、素材の復元経緯は[RESTORATION.txt](RESTORATION.txt)に記録しています。

入力の自動検証にはUnity Input Systemの仮想デバイスを使用しています。物理コントローラー2台での動作確認は未実施です。
