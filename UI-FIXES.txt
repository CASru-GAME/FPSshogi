FPSshogi UI修正記録 (2026-11-06)

対象: UI-REVIEW.txt の U01～U12。復元済み素材は保持。

・FPS: 左右それぞれにプレイヤー、駒、武器、HPバー、照準を表示。
  被弾の赤い表示と、攻撃・防御/ズーム・スキルの実際の待ち時間を追加。
・将棋: 手番、選択元、カーソル、合法手、入力結果を表示。
  持ち駒は読みやすいボタンと枚数に変更。選択中/配置中を明示。
・持ち駒: 2Pの最後の駒を使った後に表示が残る問題を修正。
  二歩判定が銀などにも適用されていた問題を修正。
・タイトル: 初期フォーカスとゲームパッド操作を修正。
  遊び方・駒の能力・感度設定・入力機器の接続表示を追加。
・接続: ゲームパッド2台、またはキーボード/マウス+ゲームパッド1台。
  対局中の切断は一時停止し、接続後に同じ対局へ戻れる。
・進行: 対戦前カウントダウン、決闘の勝者通知、ポーズを追加。
  結果は自動で消えず、再戦/タイトルを選択できる。
・表示: 1920x1080を基準に拡縮。720pの終了ボタンの欠けを解消。
  日本語フォントを同梱。

Unityでの確認:
  Open-FPSshogi.cmd から開き、Titleシーンで再生。
  新UIは再生時に GameUiBootstrap が生成します。
  元のCanvasは新UIの生成時に無効になります。
  FPSshogi > Run UI regression で実シーン回帰テスト。
  FPSshogi > Build Windows で Builds/FPSshogi/FPSshogi.exe を作成。

実装: Assets/App/Scripts/UI/
検証: Assets/Tests/Editor/UiRegressionRunner.cs
画像: UIReview/After/1080/、UIReview/After/720/
ビルド結果: Logs/ui-build-results.txt

  物理ゲームパッドでの操作感・機種ごとの入力は未確認。
